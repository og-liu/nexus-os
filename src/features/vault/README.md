# 保险库

> 存账号、密码和任何要记住的键值记录：左边群组分类、中间条目列表、右边条目的全部内容；
> 每条记录是「标题 + 自定义键值对」，外加复制、密码生成、批量移动。

| | |
|---|---|
| 入口 | `app/(app)/tools/vault/page.tsx`（一行薄壳）→ 实现住在本目录 `server/page.tsx` |
| 接口 | 无 HTTP 接口，数据入口是 Server Action（`server/actions.ts`） |
| 数据表 | `vault_groups`（`docs/数据库/保险库群组表.md`）、`vault_items`（`docs/数据库/保险库条目表.md`） |
| 状态 | ✅ 已上线（v0.9.0，2026-10-29 起） |

**这份 README 是这个工具唯一的文档**：代码结构在 §五，需求 / 界面 / 数据 / 决策 / 验收 / 坑在一～四、六、七。
原来的 `docs/功能/保险库.md` 已于 2026-11-05 并入本文件，章节编号保持不变。

## 一、要什么

**做**

- **工具页** `/tools/vault`：三栏——左栏群组导航、中栏条目列表、右栏选中条目详情。
- **落库**：两张新表，全按 `user_id` 隔离；条目的群组可为空（未分组）。
- **条目**：标题（默认「未命名」，重名自动补序号）+ **自定义字段**（键值对，可增删、可拖拽排序）；每个字段可一键复制、可一键生成 20 位随机串；**每个字段可设「默认遮挡」**——弹窗里点眼睛，保存后右栏与中栏按它显示。
- **群组**：新建 / 重命名 / 删除（二次确认；删群组不删条目，组内条目降为未分组）。
- **批量**：复选框多选 → 批量移动到指定群组 / 批量删除。
- **搜索**：只搜标题，输入即过滤。
- **目录同步**：`tool-catalog` 新增一条 `vault`（分类「生活」、状态「可用」）。

**主动放弃（本版不做，不是遗漏）**

| 放弃项 | 原因 |
|---|---|
| 字段值加密 / 主密码 | 主人明确要求一期不做（个人工作台）。**明文存储要在文档里写明白**，见《数据库/保险库条目表》§七。做一半的加密（密钥在进程里、明文进日志）比明文更危险 |
| 字段「类型」（文本 / 密码 / URL） | 类型一进来，每加一个字段就多一次下拉选择；收益只是「密码行显示成圆点」 |
| 字段值搜索 | 需求定的是「只搜标题」；要做得读 JSON 或建字段表，等真有需要再说 |
| 群组嵌套 / 群组排序 | 一层分类够用；嵌套要定义「删父组时子组怎么办」 |
| 收藏 / 星标 / 图标 / 颜色 | 全站黑白灰基调，彩色图标只会让左栏变成贴纸墙 |
| 附件 / SSH 密钥 / 2FA / 到期日 / 备注 | 参考图里的固定字段区块全部砍掉——本工具只有「标题 + 自定义字段」 |
| 删除撤销 / 回收站 | 软删除会让每条查询都得带 `deleted_at IS NULL`；二次确认更便宜 |
| 拖拽库（dnd-kit） | 只为弹窗里几行排序，引两个包不值；手写 pointer 事件足够 |
| 条目历史的版本记录 | 没有「上一次的值是多少」这种需求 |

## 二、界面

### 2.1 整体骨架

**这是全站第一个「应用型」页面，不是「文档流」页面。** 便签 / 待办 / 工作日历是「一列内容往下排、整页滚动」；保险库要的是**三栏各自滚动、整页不滚**（像 Finder / 邮件客户端）。

- 页面根 `flex h-full overflow-hidden`；三栏区 `flex min-h-0 flex-1 overflow-hidden`——**`min-h-0` 不能省**，flex 子项默认 `min-height` 是 `content`，三栏会被内容撑破、整页开始滚。
- **没有 `PageHeader`**：页签栏已经承担「我在哪、怎么切走」，再叠一条「‹ 保险库」是同一件事说两遍（主人原话「上面已经有多页签导航了，没必要多整这么一行」）。代价是页头里的**手机汉堡按钮**跟着消失，所以它挪到中栏顶行最左边（`lg:hidden`）。

```
页签栏（外壳的 TabBar，页面自己不再画标题行）
┌──────────┬─────────────────────────────┬──────────────────┐
│ 左栏 208 │ 中栏（弹性）                 │ 右栏 384          │
│ 所有条目 │ 搜索框            [新建]     │ 标题             │
│ ─ 群组   │ 标题 │ 字段1 │ 时间          │ 修改时间 [编辑][删除]│
│ ⊞ 银行 3 │ ☐ 招商银行 … ashie…          │ 卡号  8821319 [复制]│
│ + 新建群组│                             │ 密码  ***      [复制]│
└──────────┴─────────────────────────────┴──────────────────┘
```

### 2.2 左栏：群组导航

- 顶部「**所有条目**」一行 + 右侧显示**全部条目总数**（不是未分组数）——它是聚合视图，点它中栏列出这个人的全部条目。
- 下面细分隔线 + 「群组」小标题 + 右侧 `+`（新建群组）；每行「名称 + 条目数」。
- **排序：最新建的在上**（`created_at DESC`），配合「建完自动切过去」，视线不用上下找。
- 选中态黑底白字（与侧边栏一致，全站一种高亮方式）；群组行 hover（触屏常显）出现 `⋯` → 「重命名 / 删除」。
- **新建成功后自动切到那个群组**：`createGroupAction` 把新 id 放 `createdId` 返回，前端据此切视图。
- **删除群组**：确认框文案 `删除群组「银行」？该群组还有 3 条记录，删除后它们会变成未分组，记录本身不会丢失。`（没有条目的群组省略第二句）。
- 空态：「还没有群组」+「点上面的 ➕ 建第一个」。

### 2.3 中栏：条目列表

**列头是动态的**——本页最容易做错的地方：

```
列头 = 标题 + ⌈当前视图内所有条目字段名的并集，最多 4 个⌉ + 修改时间
```

- 「并集」按**首次出现顺序**排（第一条记录的字段顺序打头），保证列头稳定、不随选择跳动。
- 某条没有这一列 → 该格显示 `—`（灰）。标题列与时间列**永远存在**（前者答「这条是什么」，后者是排序依据）。
- 动态列最多 4 个；第 5 个起只在右栏看（再多列，中栏会挤成一条缝）。
- **列数随中栏自身宽度退档**（容器查询，不是视口断点——三栏时中栏只有视口一半）：< 560px 两列（标题 + 时间）；≥ 560px 加 2 个字段列；≥ 760px 加 4 个。
- 每行左侧**复选框常驻**（手机没有 hover，藏起来就永远勾不上）；行点击选中，选中整行 `bg-[#F5F5F5]`（不用蓝色高亮）。
- **整行手型光标**，**双击整行直接打开编辑弹窗**（编辑不必「先选中、再点右栏铅笔」两步）；行加 `select-none`，否则双击会顺手选中文字，看着像出 bug。
- 字段值 `truncate`，完整值去右栏；字段列默认 `***`，点右栏那只眼睛**中栏一起露**（两处共用同一份 `revealed` 状态，不然会一边露一边藏）。
- 表头「修改时间」不可点排序（排序固定时间倒序）。
- **搜索框**「搜索标题」，输入即过滤（前端过滤，不走服务端）；有输入时右侧出现 `×`；搜索改变时选中态保留（只要那条还在结果里），不在结果里就清空选中。
- **批量操作条**（勾选 ≥1 条后浮出）：`已选 3 条  [移动到 ▾] [删除]  [取消选择]`。「移动到」列出全部群组 + 第一项「未分组」，点一项即执行；「删除」二次确认 `删除选中的 3 条记录？删除后无法恢复。`；成功后清空选择、刷新列表、右栏按「当前视图第一条」重新选中。
- **空态**：`这里还没有记录`（群组视图时 `这个群组还没有记录`）+「新建一条」；搜索无结果 → `没有标题包含「xxx」的记录` + 「换个词试试」。

### 2.4 右栏：条目详情

- **是否遮挡由字段自己的 `hidden` 决定**（弹窗里设、跟着记录存）：`false` 直接显示真值，`true` 显示 `***`；点眼睛能**临时**看一眼，不写回库。
- 眼睛与复制**都常显**（有值才给）；复制永远拿真值。空值不给眼睛，那行显示灰色斜体 `（空）`。
- 值 `break-all`（密码 / 卡号没有空格，`break-words` 撑不住长串）；遮挡时用**固定 12 个星号** + 等宽 + 宽字距，一眼看出「藏起来了」——不按真实长度生成，长度本身也是信息。
- 复制成功 `toast.success("已复制")`；失败 `toast.error("复制失败，请手动选中")`。
- 编辑 / 删除在标题右侧；删除二次确认 `删除「招商银行信用卡」？删除后无法恢复。`
- 空态：**在左边选一条记录** / 这里会显示它的全部字段；点上面的「新建」也可以随时记一条。

### 2.5 新建 / 编辑弹窗

新建与编辑**共用一个组件**，差别只在初始数据与标题。

- **标题**：新建预填「未命名」并**全选**（进来直接打字就是替换）；留空保存按「未命名」处理。
- **重名自动补序号**：只对空标题 / 未命名生效（用户自己起的名不自动改——想让两条同名是合法的）。
- **群组**：原生 `select` 但 `appearance-none` 掉自带箭头、右侧自绘 `ChevronDown`（原生箭头贴边框、`padding-right` 管不到它）；不引第三方下拉。
- **自定义字段行**：`⋮⋮` 把手 + 字段名 + 值 + 🎲 + 🗑。
  - 拖拽手写 pointer 事件，按住把手上下拖实时换位；键盘 `↑` 把该行上移一位（纯指针拖拽对只用键盘的人等于不存在）。
  - 🎲 生成 20 位随机串，字符集去掉了易混字符 `0 O o 1 l I`（抄写会看错）；已有值**直接覆盖不弹确认**（想撤销就点取消）。
  - **每行的眼睛改的是这一格保存后的默认状态**：睁开 = 外面直接显示真值，闭上 = 显示 `***`；闭上时弹窗里的值输入框变圆点（`type="password"`）。新建行默认睁开，编辑时按已存值回填。
  - 字段名叫空的：保存时整行**静默丢弃**（加了一行又没填名字，说明不要这行）。
- **添加字段**：追加一行空行，焦点落到新字段名输入。
- **保存**：服务端校验失败（标题超长 / 字段过多 / 群组不属于自己）→ 弹窗内顶部红字提示、**不关窗、输入不丢**；成功 → 关窗、中栏刷新、右栏选中这条、toast **带上标题**（服务端可能把「未命名」补成「未命名 2」，所以标题从返回的快照取）。
- `⌘/Ctrl + Enter` 保存；`Esc` /「取消」/ 点遮罩**直接关闭并丢弃改动**——不做「有未保存改动就拦一下」。主人否得很干脆：「我都要取消了，为什么还要保存」。
- **移动端**：`Modal` 本身是全屏形态，字段行上下堆叠（名字在上、值在下）。

### 2.6 响应式（三档，都是独立版式，不是压缩）

全局侧边栏 `lg`(1024) 起常驻、宽 80px，所以内容区宽度 = 视口 − 80（≥ 1024）/ 视口（< 1024）。

| 档位 | 视口 | 布局 |
|---|---|---|
| 宽屏 | ≥ 1280 | **三栏并排**：左 208 / 中弹性（约 600–900）/ 右 384，各栏自滚 |
| 窄屏 PC / 平板横 | 1024–1279 | **两栏**：中 + 右 340；左栏收进抽屉，由中栏顶部「群组」按钮打开 |
| 平板竖 | 768–1023 | **两栏**：中（最小 420）+ 右（最小 300）；左栏同样走抽屉 |
| 手机 | < 768 | **单栏逐层**：列表页 → 详情页。列表页顶行最左是汉堡（页头没了），下面一行是群组横滑 chip 条；点条目切到详情页，顶部「← 返回」 |

- ≥ 768 的抽屉：点「群组」从左侧滑出 240px 面板 + 遮罩，选中后自动关闭。
- **手机为什么用横滑 chip 而不是抽屉**：手机上切群组是高频动作，抽屉要点两下（开、选）；chip 点一下就切，当前群组始终可见。
- 手机详情页整页替换列表（不是叠在下面），顶部 `← 保险库 / 群组名`，右侧「编辑」「删除」；手机弹窗全屏、字段行上下堆叠、底部按钮贴安全区。
- 三档用**互斥显隐**而不是 JS 读视口——首屏 SSR 不闪。

## 三、数据模型

```sql
CREATE TABLE IF NOT EXISTS vault_groups (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id    INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  name       TEXT    NOT NULL,
  created_at INTEGER NOT NULL,
  UNIQUE (user_id, name)
);

CREATE TABLE IF NOT EXISTS vault_items (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id    INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  group_id   INTEGER REFERENCES vault_groups(id) ON DELETE SET NULL,
  title      TEXT    NOT NULL,
  fields     TEXT    NOT NULL DEFAULT '[]',
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL
);
```

设计要点：

- **`group_id` 用 `ON DELETE SET NULL`**：删群组时条目**自动**变未分组，不需要应用层「先搬再删」，也不会漏搬而连坐删除。**前提是连接开着 `foreign_keys = ON`**（`createConnection()` 已开，SQLite 默认是关的）。
- **`fields` 存 JSON 数组**：`[{"key":"卡号","value":"8821319"}]`。用数组不用对象是为了**保序**（用户可拖拽）；这是《数据库/README》§三「一列只存一个值」的**登记例外**，理由与推翻条件见《数据库/保险库条目表》§七。
- **`(user_id, name)` 唯一**：同一个人不能有两个同名群组（左栏里两个「银行」谁也分不清）。
- **排序**：`ORDER BY updated_at DESC, id DESC`（末尾 `id DESC` 兜毫秒撞车）；**移动群组也刷新 `updated_at`**——移完立刻要在新群组里一眼看到。
- **群组表没有 `updated_at`**：改名不参与任何排序，留一列没人读的会被误以为「群组能按最近编辑排」。

## 四、关键决策

| 决策点 | 选择 | 理由 | 否决的备选 |
|---|---|---|---|
| 页面形态 | **三栏、整页不滚、各栏自滚** | 这是「反复查用」的工具，列表和详情要同时在场；滚动整页会让右栏跟着列表跑掉 | 列表页 + 详情页两跳（每次看字段都要离开列表）；抽屉详情（遮不住列表） |
| 左栏与全局侧边栏叠加 | ≥ 1280 才三栏，1024–1279 左栏收进抽屉 | 全局图标栏占 80px，三栏至少要 208+520+340=1068 的内容宽度 | 所有尺寸硬塞三栏（1024 下中栏只剩 300px，列头全挤没） |
| 列头 | 标题 + 字段并集（最多 4）+ 时间，**动态生成** | 主人原话「用户名 / URL 没了就没了，全部由自定义字段来决定」；同一群组记录结构通常一致，横向比较才有意义 | 固定三列（字段不固定只能空着）；只显示标题（信息密度太低） |
| 动态列的取法 | 当前视图内**并集**、按首次出现顺序、最多 4 | 取并集才能跨记录比较；4 列是三栏下中栏能容下的上限 | 取所选条目的字段（切条目时列头乱跳）；全部字段（每列被挤成一条缝） |
| 列数退档 | **容器查询**（中栏自身宽度） | 中栏宽度 ≠ 视口宽度（三栏时只有一半） | 视口断点（宽屏但中栏窄时照样挤） |
| 排序 | 固定 `updated_at DESC`，表头不可点 | 只有「最近动过的在最上面」一个需求；可点排序要维护 `sortKey/dir`、每列建索引，收益为零 | 点列头多列排序 |
| 搜索 | 只搜标题、前端即时过滤 | 需求定死的范围；几百条全量在前端过滤，无网络往返、无防抖延迟 | 搜字段值（要读 JSON 或建字段表）；服务端搜索（多一次往返还要处理竞态） |
| 字段排序 | **手写 pointer 拖拽 + 键盘 ↑** | 只为弹窗里几行排序，dnd-kit 两个包 ~40KB；行高固定（44px），位移 ÷ 行高 = 目标下标，十行写得完还能讲清原理 | `@dnd-kit/*`（功能强但为 5 行引入两个依赖）；HTML5 `draggable`（**触屏完全不工作**） |
| 拖拽把手 | 只在 `⋮⋮` 上响应 | 整行可拖会和「选中输入框文字」打架；有把手用户才知道能拖 | 整行可拖（手机上根本没法选文字） |
| 密码生成 | 每行一个 🎲，默认 20 位、去易混字符 | 没有字段类型，所以「生成」是**行级动作**而不是「密码类型字段的属性」 | 给字段加类型再判断；全局一个生成器面板 |
| 群组删除 | 二次确认 + **真删群组、条目降为未分组** | 删盒子不该烧掉盒子里值钱的东西；`ON DELETE SET NULL` 让这条规则由数据库保证 | 连坐删除条目（灾难）；软删除群组 |
| 群组名唯一 | 同一用户内唯一 | 左栏是导航，两个同名群组每次都要猜 | 允许重名（省一次报错，换来长期困惑） |
| 批量操作 | 复选框 + 浮出操作条 | 移动 / 删除都是多条目动作；不做批量就得一条条点 | 右键菜单（触屏没有右键）；长按多选（发现不了） |
| 弹窗 vs 独立页 | **弹窗**（复用 `ui/modal`） | 编辑时列表还在背后，改完立刻看到它复位到哪；`Modal` 已有移动端全屏形态 | 独立编辑页（为几个字段开一页）；右栏原地编辑（三栏里最窄，输入框会被挤爆） |
| 字段值的遮挡 | **默认状态存在字段上**（`fields[].hidden`）；临时「看一眼」只在本会话翻转、不写回 | 「这一格打开时想不想看见」是**对数据的设定**，属于记录；「这一眼谁在看」是临时状态，属于屏幕。中栏与右栏**共用同一份临时状态**，否则会一边露一边藏 | 全局一个眼睛开关（分不清哪个字段）；把临时观看也写回库（刷新后又变，用户以为没生效） |
| 复制 | 每个字段一个复制图标 | 保险库最常用的动作是「把值拿走」 | 整条复制（字段混在一起，粘出去还得拆） |
| 空态文案 | 「在左边选一条记录」+ 备选路径 | 先说要做什么动作，再给第二条路；比「暂无数据」有用 | 「没有选择对象」（机器语气） |

## 五、代码结构（三层）

**这就是原来的「文件落点」一节。**

`client/` —— 浏览器（`"use client"`）。不碰 db、不 import `server/`。

| 文件 | 职责 |
|---|---|
| `vault-view.tsx` | 页面主视图：状态中枢（选中项、视图、搜索、批量、`revealed`） |
| `group-nav.tsx` | 左栏：所有条目 + 群组 + 群组的增删改 |
| `item-list.tsx` | 中栏：搜索、动态列头、复选框、批量条、空态 |
| `item-detail.tsx` | 右栏：详情（眼睛 / 复制 / 编辑 / 删除 / 空态） |
| `item-dialog.tsx` | 新建 / 编辑条目弹窗（字段增删 + 拖拽 + 生成 + 遮挡开关） |
| `field-row.tsx` | 弹窗里的一行自定义字段（把手 / 两个输入 / 🎲 / 🗑） |
| `use-field-drag.ts` | 手写拖拽排序 hook（Pointer 事件 + 键盘 ↑） |
| `dialogs.tsx` | 群组的新建 / 重命名（同一个表单，两处共用） |

`server/` —— 服务端。碰 db 的文件开头有 `import "server-only"`。

| 文件 | 职责 |
|---|---|
| `page.tsx` | 工具页接线：`requireUser()` → 取群组与条目 → 渲染视图 |
| `actions.ts` | Server Actions（`"use server"`）：群组与条目的增删改、批量移动 / 删除，每个都先 `requireUser()` |
| `vault.ts` | 数据访问（`server-only`）：群组 / 条目的增删改查、批量、字段并集 |
| `vault.test.ts` | 数据层单测：`user_id` 隔离、删群组不删条目（`ON DELETE SET NULL`） |

`shared/` —— 两端共用，只碰纯数据。

| 文件 | 职责 |
|---|---|
| `vault.ts` | 类型与纯函数：字段 JSON 编解码、中栏列头 `collectFieldKeys` |
| `validate.ts` | 服务端校验：标题、字段数组、群组归属（两条静默规则：空名字段整行丢弃、值不动空格） |
| `validate.test.ts` | 校验边界（验收 20–22） |
| `password.ts` | 随机密码生成：Web Crypto + 拒绝采样 + 去易混字符 |
| `password.test.ts` | 生成器单测（长度 / 四类字符 / 无偏 / 无易混） |

**从哪开始读**：`server/page.tsx` → `client/vault-view.tsx`（三栏状态）→ `server/vault.ts`（落地）。

**混合体拆开**：`vault.ts` 原先一个文件里既有纯函数又有数据访问——碰库的留在 `server/vault.ts`
（带 `server-only`），纯的进 `shared/vault.ts`，因为客户端要跑 `collectFieldKeys` 与字段编解码。

**工具接入方式**：工具卡统一链到 `/tools/${slug}`，手写路由 `/tools/vault` 是**静态段**，Next 路由
匹配里静态段优先，所以卡片点进来自动命中真页面。接入只要两步：目录里登记一条 + 建同名静态路由目录
（`app/(app)/tools/vault/page.tsx` 薄壳 + 本目录 `server/page.tsx` 实现）。
（2026-10-30 起 `/tools/[slug]` 兜底路由已随占位条目删除，未知 slug 直接 404。）

**约束**：`client/` 与 `shared/` 不 import `server/`（`import type` 与 `"use server"` 的 actions 除外）；
表结构唯一权威仍是 `initSchema()`；不新增运行时依赖（拖拽手写）。

## 六、验收标准

**正常路径**

1. 打开 `/tools/vault`：三栏出现；左栏「所有条目 (0)」；中栏「这里还没有记录」；右栏「在左边选一条记录」。
2. 左栏 `+` → 输入「银行」→ 群组出现、显示 `(0)`；重名再建 → 「已存在同名群组」，不新增。
3. 「新建」→ 弹窗、标题预填「未命名」且全选；加两个字段（卡号 / 8821319、密码 / 点 🎲 后是 20 位随机串）→ 保存 → 弹窗关、中栏出现一行、右栏立刻显示两个字段。
4. 中栏列头出现「标题 / 卡号 / 密码 / 修改时间」——**字段名列头来自数据**，不是写死的。
5. 再建一条只有「客服电话」的记录 → 列头变「标题 / 卡号 / 密码 / 客服电话 / 修改时间」的前 4 个字段 + 时间；第一条的「客服电话」格显示 `—`。
6. 点右栏某个值的复制图标 → toast「已复制」；粘贴到别处是完整值。
7. 「编辑」→ 弹窗回填；拖住第一行 `⋮⋮` 往下拖到第二行 → 松手两行交换；保存 → 右栏顺序同步变了，刷新后仍是新顺序。
8. 弹窗里聚焦字段名输入，按 `↑` → 该行上移一位（键盘也能排序）。
9. 编辑里把群组从「未分组」改成「银行」→ 保存 → 中栏两个视图数量都变。
10. 在「银行」里勾两条 → 操作条「已选 2 条」→「移动到 ▾」选「未分组」→ 两条离开当前视图、左栏计数变化。
11. 勾两条 →「删除」→ 确认框写明「删除选中的 2 条记录」→ 确认 → 两条消失、右栏按当前视图第一条重新选中。
12. 搜索「银行」→ 中栏只剩标题含「银行」的记录，无结果文案正确；`×` 恢复。
13. 左栏群组 `⋯` →「重命名」→ 改成「银行卡」→ 左栏立刻更新，条目不变。
14. 左栏群组 `⋯` →「删除」→ 文案含「该群组还有 2 条记录，删除后它们会变成未分组」→ 确认 → 群组消失；点「所有条目」两条仍在，右栏显示「未分组」。
15. 切换群组：中栏自动选中该群组**第一条**，右栏立即渲染。
16. 刷新页面：数据都在，顺序与刷新前一致（`updated_at DESC`）。

**负面路径**

17. 未登录直接访问 `/tools/vault` → 跳 `/login`。
18. A 的数据被 B 查询（数据层单测，两个 `user_id`）→ B 取不到 A 的群组与条目、改不动 A 的行。
19. 用 B 的 `user_id` 建条目时把 `group_id` 塞成 A 的群组 id → 服务端拒绝（`群组不存在`），不落库。
20. 字段名全空、只留几行空行 → 保存时静默丢弃，落库 `fields` 是 `[]`，界面不报错。
21. 标题 200 字 → 服务端拒绝并提示，弹窗不关、输入不丢。
22. 直接调 Server Action 传非法 `fields` → 拒绝，不抛未捕获异常。
23. 未选中任何条目时点批量操作 → 操作条根本不出现。
24. 删除当前选中的条目 → 右栏回空态或自动选中下一条（不留残影）。
25. 字段值存 `<img src=x onerror=alert(1)>` → 按原文字面显示，无脚本执行。

**响应式**

26. 1440px：三栏并排（左 208 / 中弹性 / 右 384）；列头 4 个字段列；三栏各自滚动，滚中栏时整页不动。
27. 1280px：三栏仍在；中栏收窄后列头自动退到 2 个字段列（容器查询生效）。
28. 1100px：两栏（中 + 右 340）；左栏消失、中栏顶部出现「群组」按钮，点开抽屉可切群组。
29. 768px：两栏（中 ≥ 420 + 右 ≥ 300），列表只显示标题与时间。
30. 375px：单栏列表页（群组横滑 chip 条）；点一条进详情页，顶部「← 保险库」；编辑 / 删除在右上；点「←」回列表，群组与滚动位置保留。
31. 375px 弹窗：全屏、字段行上下堆叠、底部按钮不被安全区遮挡。

**门禁**

32. `next typegen` / `typecheck` / `lint` / `test` / `build` 全过。
33. 单测覆盖：群组唯一、删群组后条目 `group_id` 变 NULL、`user_id` 隔离、批量移动 / 删除、排序（时间倒序 + id 兜底）、字段 JSON 往返（非法 JSON 不崩）、标题校验边界、未命名自动编号、密码生成（长度 / 字符集 / 无易混 / 两次不同）。

## 七、已知的坑

| 坑 | 机制 | 对策 |
|---|---|---|
| 删群组后条目「消失」 | `foreign_keys` 默认**关**，`ON DELETE SET NULL` 不执行，子行变成孤儿 | `createConnection()` 已开 `foreign_keys = ON`；单测专断言「删群组后条目 `group_id` 为 NULL、条目还在」 |
| 三栏撑破页面 | flex 子项默认 `min-height: auto`，内容把栏撑高、整页开始滚 | 三栏父容器 `flex min-h-0 flex-1 overflow-hidden`，每栏自己 `overflow-y-auto`；`min-h-0` 不能省 |
| 中栏列头错位 | 动态列数变化时 `table` 列宽会跳 | `table-fixed` + 标题列固定比例，字段列等分剩余宽度 |
| 容器查询不生效 | Tailwind 的 `@[560px]:` 需要父元素显式 `@container` | 中栏根节点加 `@container`，**别在中间再套一层没加的 div**——它找的是最近的容器祖先 |
| 手写拖拽在手机上拖动整页 | 触摸时浏览器把 pointermove 当滚动 | 把手加 `touch-action: none`；`pointerdown` 时 `setPointerCapture`，只认设定的 pointerId |
| 拖拽行高不固定导致下标算错 | 用「位移 ÷ 行高」算目标位置，行高必须已知 | 字段行固定 `h-11`（44px），不用 `min-h`；换行时值输入框内部滚动 |
| 拖拽时输入框失焦 | 点把手会先 `blur` 值输入框 | 允许失焦（拖完不回输入框），保存时统一从 state 读 |
| 误关弹窗丢改动 | `Modal` 自带 `Esc` / 点遮罩关闭 | **不做拦截**（主人明确否决「按两次」）：取消就是取消，要保住就点保存 |
| 复制在非 HTTPS 下失败 | `navigator.clipboard` 只在安全上下文可用 | 线上是 HTTPS；失败分支给 `toast.error`，让用户能手动选中 |
| 搜索时选中态指向被过滤掉的条目 | 选中 id 还在，但那条已不在结果里 | 过滤后校验：不在结果里就清空选中（右栏回空态） |
| 批量操作后选中残留 | 删除 / 移动后 id 已失效 | 成功后统一「清空选择 + 按当前视图重新选第一条」 |
| JSON 字段被外部改坏 | 库里 `fields` 是文本，可能不是合法 JSON | 读取时 `try/catch`，坏数据当 `[]` 并记服务端日志，不让整个列表 500 |
| 未命名编号无限增长 | 每次新建都要查一遍同名 | 只在标题为空或恰为「未命名」时查，且一条 `LIKE '未命名%'` 取回再算序号 |
| 时间显示跨时区漂移 | 服务端容器是 UTC | 复用 `lib/format.ts` 的 `formatDateTime`（显式 +8） |
| 三栏页在手机上整页滚 | 手机是单栏逐层，但详情页内容长时会滚 | 详情页自身 `overflow-y-auto`，页头固定 |
| 演示数据残留 | 手动测的记录会被当真实数据 | 验收结束前清掉测试行（或换测试账号跑） |
