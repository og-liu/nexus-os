# 开发路线图

Nexus OS 的版本规划与里程碑，记录各阶段的开发重点。

---

## v0.1.0 — 基础框架（当前版本）

**目标**：搭建项目骨架，确立技术栈与架构，完成 UI 框架。

- [x] 项目初始化（Next.js 16 + React 19 + TypeScript + pnpm）
- [x] 全局布局搭建（侧边栏 + 主内容区 + 页脚）
- [x] 公共组件开发（Sidebar、PageHeader、Footer、LogoIcon）
- [x] shadcn/ui 组件库集成（avatar、badge、button、card、dropdown-menu、progress、switch、tabs）
- [x] 首页 Dashboard（系统概览、快捷工具入口、最近活动）
- [x] 工具中心页面（6 个工具卡片展示，状态标注）
- [x] 全部模块路由注册（tools / files / agent / knowledge / automation / settings）
- [x] 设置页面框架（AI 模型配置 + 工具目录分区）
- [x] 项目文档体系搭建（docs/ 目录）

---

## v0.2.0 — 工具中心 MVP

**目标**：实现核心工具的实际功能，打通前端到后端的完整链路。

- [ ] 图片压缩工具（客户端压缩 / 服务端压缩）
- [ ] 图片格式转换工具
- [ ] OCR 文字识别（集成 OCR 引擎）
- [ ] 文本处理工具（JSON 格式化、编码转换、正则测试）
- [ ] 工具执行引擎（统一的工具注册、参数校验、执行调度）
- [ ] 文件上传/下载通用组件

---

## v0.3.0 — 文件管理

**目标**：实现本地文件浏览与管理功能。

- [ ] 本地目录浏览（树形视图 + 列表视图）
- [ ] 文件搜索（文件名、内容搜索）
- [ ] 文件预览（图片、文本、PDF）
- [ ] 以图找图功能
- [ ] 文件批量操作（重命名、移动、删除）

---

## v0.4.0 — AI Agent

**目标**：集成 AI 大模型，实现智能对话与工具调用。

- [ ] AI 模型接入层（支持多模型切换）
- [ ] 对话界面（流式输出、Markdown 渲染、代码高亮）
- [ ] 意图理解引擎（自然语言 → 结构化意图）
- [ ] 工具调用协调器（Agent 自动选择并调用工具）
- [ ] 对话历史管理
- [ ] 上下文窗口管理

---

## v0.5.0 — 知识库

**目标**：构建个人知识管理中心。

- [ ] 知识条目 CRUD（笔记、文档、链接）
- [ ] 知识分类与标签系统
- [ ] 文本向量化与存储
- [ ] 智能语义检索
- [ ] 知识图谱可视化（远期）
- [ ] AI Agent 知识库读写集成

---

## v0.6.0 — 自动化引擎

**目标**：实现工作流编排与自动化任务执行。

- [ ] 工作流定义（可视化编辑器 / DSL）
- [ ] 任务调度器（定时触发、事件触发）
- [ ] 流程编排引擎（条件分支、并行、循环）
- [ ] 执行监控与日志
- [ ] 错误处理与重试机制
- [ ] 预设工作流模板

---

## v1.0.0 — 插件系统与正式发布

**目标**：开放插件能力，完成首个正式版本。

- [ ] 插件系统架构设计
- [ ] 插件描述规范（plugin.json）
- [ ] 插件注册与生命周期管理
- [ ] 插件 SDK（工具插件、UI 插件、数据插件）
- [ ] 插件市场（浏览、安装、更新）
- [ ] 性能优化与安全审计
- [ ] 用户文档与开发者文档

---

## 版本策略

- **v0.x.x**：开发阶段，功能逐步交付，每个次版本号对应一个核心模块
- **v1.0.0**：首个正式发布版本，具备完整的工具中心 + AI Agent + 知识库 + 自动化 + 插件系统
- 版本号遵循 [Semantic Versioning](https://semver.org/) 规范
