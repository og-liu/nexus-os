# 开发路线图

Nexus OS 的版本规划与里程碑，记录各阶段的开发重点。

---

## v0.1.0 — 基础框架（当前版本）

**目标**：搭建项目骨架，确立技术栈与架构，完成全站 UI 框架与核心页面 mock。

- [x] 项目初始化（Next.js 16 + React 19 + TypeScript + pnpm）
- [x] 全局布局搭建（AppShell：桌面常驻侧边栏 + 移动端抽屉 + PageHeader 吸顶 + Footer）
- [x] 公共组件开发（Sidebar、AppShell、PageHeader、Footer、LogoIcon）
- [x] shadcn/ui 组件库集成（avatar、badge、button、card、dropdown-menu、progress、switch、tabs）
- [x] 首页 Dashboard（系统概览、快捷工具入口、最近活动、右栏常驻卡片）
- [x] 工具中心页面（59 个工具卡片展示、搜索 + 分类筛选、三档响应式；工具均为 mock）
- [x] AI Agent 页面 UI mock（对话消息流、任务卡片、语音/图片输入、左侧会话栏；无真实模型调用，能力实现见 v0.4.0）
- [x] 知识库页面 UI mock（知识流/我的文章/收件箱/回收站/订阅源/自测/回顾 7 个 section 全前端交互；无真实存储与 AI，能力实现见 v0.5.0）
- [x] 全站响应式三档断点（移动 <1024 抽屉 / 窄屏 PC 1024-1279 / 宽屏 ≥1280）
- [x] 全部模块路由注册（tools / files / agent / knowledge / automation / settings）
- [x] 设置页面框架（AI 模型配置 + 工具目录分区）
- [x] 项目文档体系搭建（docs/ 目录）

---

## v0.2.0 — 工具中心 MVP

**目标**：实现核心工具的实际功能，打通前端到后端的完整链路。

- [ ] 图片压缩工具（客户端压缩 / 服务端压缩）
- [ ] 图片格式转换工具
- [ ] OCR 文字识别（集成 OCR 引擎）
- [ ] 文本处理工具（JSON 格式化、编码转换、正则测试）
- [ ] 工具执行引擎（统一的工具注册、参数校验、执行调度）
- [ ] 文件上传/下载通用组件

---

## v0.3.0 — 文件管理

**目标**：实现本地文件浏览与管理功能。

- [ ] 本地目录浏览（树形视图 + 列表视图）
- [ ] 文件搜索（文件名、内容搜索）
- [ ] 文件预览（图片、文本、PDF）
- [ ] 以图找图功能
- [ ] 文件批量操作（重命名、移动、删除）

---

## v0.4.0 — AI Agent

**目标**：集成 AI 大模型，实现智能对话与工具调用。

- [ ] AI 模型接入层（支持多模型切换）
- [ ] 对话界面（流式输出、Markdown 渲染、代码高亮）
- [ ] 意图理解引擎（自然语言 → 结构化意图）
- [ ] 工具调用协调器（Agent 自动选择并调用工具）
- [ ] 知识库优先问答（RAG：先查库命中即答，未命中再联网；依赖 v0.5.0 知识库底座）
- [ ] 一句话多步任务（自主规划筛选→归类→提炼→落盘）
- [ ] 对话历史管理
- [ ] 上下文窗口管理

---

## v0.5.0 — 知识库

**目标**：构建个人知识管理中心，跑通「采集→审查→整理→入库→阅读」核心流水线。

- [ ] 知识条目数据模型与存储（笔记、文档、链接；内容格式待定，见 product-vision.md 待讨论清单）
- [ ] 采集：网页/链接抓取、手动粘贴内容入库
- [ ] 审查收件箱（Inbox）：待处理条目快速预览、留/弃
- [ ] AI 整理：长文提炼为结构化条目（要点+标签+待办）、自动分类打标签、去重合并、新旧内容关联
- [ ] 知识分类与标签系统
- [ ] 阅读视图 + 轻量编辑（改 AI 初稿）
- [ ] 关键词检索 + 文本向量化与语义检索
- [ ] AI Agent 知识库读写集成（为 v0.4.0 的 RAG 问答提供底座）
- [ ] 知识图谱可视化（远期，可顺延至迭代二）

---

## v0.6.0 — 自动化引擎

**目标**：实现工作流编排与自动化任务执行。

- [ ] 工作流定义（可视化编辑器 / DSL）
- [ ] 任务调度器（定时触发、事件触发）
- [ ] 流程编排引擎（条件分支、并行、循环）
- [ ] 定时采集与综述（订阅源定时抓取 → 技术晨报/每日每周综述）
- [ ] 保鲜扫描（定期标记过时/失效内容，提示归档）
- [ ] 智能复习与测验（按遗忘曲线推回顾条目、出闪卡自测）
- [ ] 执行监控与日志
- [ ] 错误处理与重试机制
- [ ] 预设工作流模板

---

**目标**：开放插件能力，完成首个正式版本。

- [ ] 插件系统架构设计
- [ ] 插件描述规范（plugin.json）
- [ ] 插件注册与生命周期管理
- [ ] 插件 SDK（工具插件、UI 插件、数据插件）

- [ ] 用户文档与开发者文档

---

## 版本策略

- **v0.x.x**：开发阶段，功能逐步交付，每个次版本号对应一个核心模块
- **v1.0.0**：首个正式发布版本，具备完整的工具中心 + AI Agent + 知识库 + 自动化 + 插件系统
- 版本号遵循 [Semantic Versioning](https://semver.org/) 规范
