# 界面设计规范

> 本文只回答一件事：**界面长什么样。** 色彩、排版、圆角、布局骨架、组件形态。
> 技术选型与依赖版本见《技术栈说明》；文件放哪见《项目目录结构说明》；本文只管「视觉的规矩」。
>
> 维护规则：改界面前，**先改本文，再改代码**。文中的每个色值与类名都可直接照抄。

---

## 一、设计基调

四条基本主张，所有具体规则都是它们的推论：

1. **黑白灰 + 直角。** 界面不表达色彩偏好，颜色只留给「状态」和「当前选中」。
2. **层次靠底色深浅交替，不靠投影和描边。**
   `灰页面（#ECECEC） → 白卡片（#FFFFFF） → 灰内嵌块（#F5F5F5） → 白图标底（#FFFFFF）`。
3. **高信息密度。** 12px / 13px / 14px 是主力字号，10px 也在使用；界面宁可紧，不要松。
4. **装饰为零。** 没有渐变、没有彩色阴影、没有玻璃拟态、没有圆润大圆角。唯一的「装饰」是分组标题前的黑色短竖条。

## 二、色彩

### 2.1 背景层次

| 用途 | 色值 | Tailwind |
|---|---|---|
| 浏览器窗口底色（`body`） | `#F5F7FA` | `bg-[#F5F7FA]` |
| 主内容区 | `#ECECEC` | `bg-[#ECECEC]` |
| 侧边栏 / 页头 / 卡片内嵌块 | `#F5F5F5` | `bg-[#F5F5F5]` |
| 页脚 | `#ECECEC` | `bg-[#ECECEC]` |
| 卡片 | `#FFFFFF` | `bg-white` |
| 页头右侧控件容器 | `#ECECEC` | `bg-[#ECECEC]` |

> 内嵌块（统计块、工具块、图标底、便签、代码块）在**白卡片内部**用 `#F5F5F5`；白卡片内部再嵌一层白（图标底）时用 `bg-white`，形成「灰—白—灰—白」的交替节奏。

### 2.2 文字层级

| 语义 | 色值 | 用途 |
|---|---|---|
| 主文本 | `#000000` | 标题、正文、数值、当前选中项 |
| 卡片内图标 | `#1F1F1F` | 32/40px 灰底图标块里的图标 |
| 次要文字 | `#666666` | 可交互的次级图标与文字、默认态控件文本 |
| 辅助文字 | `#8A8A8A` | 字段名、描述、副标题 |
| 弱化文字 | `#999999` | 时间戳、计数、占位符、单元后缀 |
| 最弱文字 | `#A0A8B4` | 页脚、极不重要的说明 |
| 反白 | `#FFFFFF` | 黑底之上的文字与图标 |

### 2.3 状态与强调色

全站唯一有色彩倾向的「面」是导航激活底色，其余色彩只以**点**或**小面积**形式出现。

| 语义 | 色值 | 形态 |
|---|---|---|
| 运行中 / 正常 | `#22C55E` | 状态点 |
| 未配置 / 已暂停 | `#D0D0D0` | 状态点 |
| 错误（Toast） | `#B91C1C` | 图标 |
| 警告（Toast） | `#9A6B0A` | 图标 |
| 危险等级（知识条目） | `red-500` | 状态点 |
| 导航激活底色 | `#d5e3f6` | 面（侧边栏与二级栏） |

**状态一律用「1.5px 圆点 + 灰色文字说明」表达，不使用彩色徽章（Badge）。** 圆点尺寸固定 `h-1.5 w-1.5 rounded-full`。

### 2.4 边框与分隔

| 用途 | 色值 |
|---|---|
| 侧边栏右边框、二级栏右边框、输入框描边 | `#E5E5E5` |
| 页头下边框 | `#E8E8E8` |
| 列表分隔线（`divide-y`）、KPI 分隔线（`divide-x`）、进度条槽 | `#F0F0F0` |
| 虚线空状态描边、未选中的复选框边框 | `#D9D9D9` / `#D0D0D0` |

### 2.5 交互态

| 元素 | 规则 |
|---|---|
| 黑底按钮 hover | `hover:bg-[#333333]`（底色变深，文字保持纯白） |
| 黑底小按钮 hover | `hover:opacity-85`（图标类小按钮可用，视觉更轻） |
| 灰底元素 hover | 加深一档：`#F5F5F5 → #ECECEC`，或 `#ECECEC → #EDEDED` |
| 二级/弱化文字 hover | 变为 `text-[#000000]` |
| 侧栏导航 hover | `hover:bg-[#ededed]`（非激活）、`bg-[#d5e3f6]`（激活） |
| 输入框 focus | 描边由 `#E5E5E5` 变纯黑：`focus:border-[#000000]`；**不加外发光（ring）** |
| 禁用态 | `disabled:opacity-30` ~ `disabled:opacity-50`，鼠标 `cursor-not-allowed` |
| 「开发中」的元素 | 整体降透明度 `opacity-60`，hover 时恢复 `hover:opacity-100` |

## 三、圆角与阴影

### 圆角

| 形态 | 值 | 适用范围 |
|---|---|---|
| 默认 | `rounded-[2px]` | **一切矩形容器**：卡片、按钮、输入框、标签、图标底、气泡、下拉项、搜索框 |
| 圆形 | `rounded-full` | 本身就是圆形的元素：状态点、黑胶唱片、圆形播放按钮、手机端筛选 chips、计数徽标 |
| 例外 | `rounded-xl`（14px） | **仅**侧边栏与二级栏的导航项高亮块 |

> 2px 是这套界面的性格所在：既不是尖角（会显得廉价），也不是圆角（会显得松软）。不要用 `rounded-md` / `rounded-lg`。

### 阴影

| 场景 | 值 |
|---|---|
| 可交互卡片 hover 抬起 | `hover:-translate-y-0.5 hover:shadow-[0_4px_12px_rgba(0,0,0,0.08)]` |
| 全局提示（Toast） | `shadow-[0_16px_48px_rgba(0,0,0,0.18)]` |
| 手机端抽屉 | `shadow-xl` |
| 下拉菜单 / 浮层 | 用 shadcn 默认 |

**常规卡片不带阴影、不带边框。** 阴影只表示「这个东西浮起来了或可以点」。

## 四、排版

### 4.1 字体

| 字体 | 加载方式 | CSS 变量 | 用途 |
|---|---|---|---|
| Noto Sans SC（可变字体） | `next/font/local` 自托管 | `--font-noto-sans-sc` | 中文正文（第一优先） |
| Geist Sans | `next/font/google` | `--font-geist-sans` | 西文正文（中文回退后的第二选择） |
| Geist Mono | `next/font/google` | `--font-geist-mono` | 代码、等宽数字 |
| Sekuya | `next/font/local` 自托管 | `--font-sekuya` | 品牌名 `NEXUS OS`（装饰性，仅此一处） |

字体回退链在 `globals.css` 的 `@theme inline` 中定义：

```css
--font-sans: var(--font-noto-sans-sc), var(--font-geist-sans), sans-serif;
```

根节点统一挂 `antialiased`。品牌名用内联 `fontFamily: "var(--font-sekuya)"` + `letterSpacing: "0.1em"`。

### 4.2 字号阶梯

| 字号 | Tailwind | 用途 |
|---|---|---|
| 10px | `text-[10px]` | 角标、时长、标签内小字、次级元数据 |
| 11px | `text-[11px]` | 节日/状态小徽标、极简提示 |
| 12px | `text-xs` | **主力**：字段名、描述、副标题、时间戳、计数、按钮小字 |
| 13px | `text-[13px]` | 紧凑正文：会话标题、便签正文、工具名、下拉项 |
| 14px | `text-sm` | **主力**：正文、卡片标题、列表主文本、按钮 |
| 15px | `text-[15px]` | 会话列表项、Toast 文本 |
| 20px | `text-xl` | 页面主标题（桌面）、KPI 数值、问候语 |
| 30px | `text-3xl` | 仪表盘时钟（唯一一处） |

### 4.3 字重与数字

- 字重三档：常规 `400`（正文）、中等 `500`（按钮、列表主文本）、半粗 `600`（标题、KPI 数值、当前选中项）。不用 `700` 及以上。
- **一切会变化的数字用 `tabular-nums`**：时钟、KPI、进度百分比、计时、计数。等宽数字防止刷新时宽度跳动。
- 时钟、代码、时长等本身是「机器数字」的，用 `font-mono`。
- 正文行高：紧凑列表靠间距控制（不加 `leading-*`）；阅读型文本用 `leading-relaxed`（1.625）或 `leading-7`。Markdown / 快照阅读区用 `line-height: 1.7 ~ 1.8`。

## 五、布局骨架

### 5.1 整体结构

```
┌────────┬──────────────────────────────────────────┐
│        │  页头 PageHeader（h-16，吸顶，bg #F5F5F5）   │
│ 侧边栏  ├──────────────────────────────────────────┤
│ 图标栏  │                                          │
│  w-20  │   主内容区（overflow-y-auto，bg #ECECEC）   │
│ 常驻   │   普通页：px-4 py-4 md:px-6 md:py-6         │
│        │   满高页：h-[calc(100%-4rem)]，左右栏各自滚动 │
│        ├──────────────────────────────────────────┤
│        │  页脚 Footer（bg #ECECEC，py-3，text-xs）    │
└────────┴──────────────────────────────────────────┘
```

整页 `flex h-screen overflow-hidden`，**禁止整页横向滚动**。

### 5.2 尺寸表

| 部位 | 值 |
|---|---|
| 一级侧边栏（桌面） | `w-20`，`border-r border-[#E5E5E5]`，`bg-[#F5F5F5]`，`hidden lg:flex` |
| 侧边栏导航项 | `rounded-xl px-4 py-4`，图标 `h-6 w-6` |
| 侧边栏 Logo | `h-9 w-9`，居中 |
| 二级栏（页面内左栏） | `w-[260px]`，满高 `overflow-y-auto`，`border-r border-[#E5E5E5]`，`bg-[#F5F5F5]` |
| 页头 | `sticky top-0 z-20 h-16`，`border-b border-[#E8E8E8]`，`bg-[#F5F5F5]` |
| 页脚 | `px-4 py-3 md:px-6`，`text-xs text-[#A0A8B4]` |
| 手机抽屉 | `w-64`，`shadow-xl`，遮罩 `bg-black/40`，打开时锁 `body` 滚动 |

### 5.3 内容区规则

- **内容容器不设 `max-width`**，100% 铺满内容区，只留内边距。内部元素自行限宽（消息气泡 `max-w-[70%]` 桌面 / `max-w-[85%]` 移动）。
- 板块间距：仪表盘 `space-y-4`；分组式长页面（工具中心）`space-y-8`，组内 `space-y-3`。
- 网格间隙统一 `gap-3`（紧凑卡片）或 `gap-4`（信息卡片）。
- 卡片内边距统一 `p-5`（大卡）/ `p-4`（列表卡）/ `p-3`（内嵌小块）/ `p-2`（紧凑块）。
- 图标底块尺寸：`h-8 w-8`（列表行、快捷工具）或 `h-10 w-10`（工具卡）。

## 六、响应式

以 Tailwind 内置断点为准，核心分界是 **lg（1024px）**。

| 档位 | 宽度 | 布局 |
|---|---|---|
| 移动 | < 1024px | 抽屉导航 + 汉堡按钮；卡片单列；chips 横滑筛选 |
| 窄屏 PC | 1024–1279px | 常驻图标栏；紧凑控件（搜索收成图标、筛选收成下拉） |
| 宽屏 PC | ≥ 1280px | 完整搜索栏、标签并排、网格多列 |

**前缀归类规则（重要，别用错）：**

| 类别 | 前缀 | 说明 |
|---|---|---|
| 结构性布局 | `lg:` | 显隐、排列方向、栏宽 — 在 1024px 整档切换 |
| 字号 / 间距 / 内边距 | `md:` | 768px 起生效，保证平板上的文字密度 |
| 宽屏增量增强 | `xl:` | 完整搜索栏、网格列数。**不用它做显隐分界** |

典型写法：

```tsx
"grid grid-cols-1 gap-4 px-4 py-4 md:px-6 xl:grid-cols-3"
"hidden lg:flex"          // 桌面常驻侧边栏
"text-base md:text-xl"    // 页头标题：排版档用 md
```

## 七、组件形态

以下模式是这套界面的「零件库」。实现时直接照抄类名，不要即兴发挥。

### 7.1 卡片

```tsx
<div className="rounded-[2px] bg-white p-5">
```

无边框、无阴影。可点击的卡片才加抬起效果：

```tsx
className="group rounded-[2px] bg-white p-4 transition-all hover:-translate-y-0.5 hover:shadow-[0_4px_12px_rgba(0,0,0,0.08)]"
```

### 7.2 分组标题（SectionTitle）

卡片内所有分组标题统一此形态，是界面唯一的装饰语言：

```tsx
<div className="flex items-center gap-2">
  <div className="h-3.5 w-[3px] bg-[#000000]" />
  <h2 className="text-sm font-semibold text-[#000000]">标题</h2>
</div>
```

右侧可跟**弱化计数**或**跳转链接**：

```tsx
<span className="text-xs text-[#999999]">12</span>
<Link className="flex items-center gap-1 text-xs text-[#8A8A8A] transition-colors hover:text-[#000000]">
  查看全部 <ArrowRight className="h-3 w-3" />
</Link>
```

### 7.3 主操作按钮（CTA）

页面/区块的主操作一律黑底白字，直角：

```tsx
className="flex items-center justify-center gap-2 rounded-[2px] bg-[#000000] px-4 py-2 text-sm font-medium text-white transition-colors hover:bg-[#333333]"
```

尺寸档：`px-2.5 py-1 text-xs`（行内小操作）、`px-3 py-2.5 text-sm`（二级栏顶部通栏按钮）、`px-4 py-2 text-sm`（常规）。
二级栏顶部是**通栏黑底按钮**：`flex w-full items-center justify-center gap-2 rounded-[2px] bg-[#000000] px-3 py-2.5 text-sm font-medium text-white`。

### 7.4 hover 反色（可点击图标块）

常态「浅底深图标」，hover 反转为「黑底白图标」：

```tsx
<div className="group flex items-center gap-3 rounded-[2px] bg-[#F5F5F5] p-2 transition-colors hover:bg-[#ECECEC]">
  <div className="flex h-8 w-8 items-center justify-center rounded-[2px] bg-white transition-colors group-hover:bg-[#000000]">
    <Icon className="h-4 w-4 text-[#1F1F1F] transition-colors group-hover:text-white" />
  </div>
  <span className="truncate text-[13px] text-[#000000]">名称</span>
</div>
```

### 7.5 状态点

```tsx
<span className="flex items-center gap-1.5 text-xs text-[#8A8A8A]">
  <span className="h-1.5 w-1.5 rounded-full bg-[#22C55E]" />
  正常
</span>
```

### 7.6 列表行

卡片内列表靠 `divide-y divide-[#F0F0F0]` 分隔，行高由 `py-2.5` / `py-3` 控制；主文本 `text-sm font-medium text-[#000000]` + 次行 `text-xs text-[#8A8A8A]`；右侧元信息 `text-xs text-[#999999]`，用 `ml-3 shrink-0 whitespace-nowrap` 固定不动。

### 7.7 KPI 条

```tsx
<div className="grid grid-cols-3 divide-[#F0F0F0] sm:grid-cols-5 sm:divide-x">
  <div className="px-4 first:pl-0 last:pr-0">
    <p className="text-xs text-[#8A8A8A]">可用工具</p>
    <p className="mt-1 text-xl font-semibold tabular-nums text-[#000000]">6</p>
  </div>
</div>
```

### 7.8 进度条

槽 `h-1 w-full bg-[#F0F0F0]`，填充 `h-full bg-[#000000]`，直角。小尺寸（卡片内任务）可用 `h-1` + 圆角 `rounded-full` + 浅槽。

### 7.9 标签（Tag / Chip）

| 形态 | 类名 |
|---|---|
| 卡片内小标签 | `rounded-[2px] bg-[#F5F5F5] px-1.5 py-0.5 text-[10px] text-[#666666]` |
| 筛选 chip（桌面） | `rounded-[2px] px-3 py-1.5 text-xs font-medium`，激活 `bg-[#000000] text-white`，未激活 `text-[#8A8A8A] hover:text-[#000000]` |
| 筛选 chip（移动） | 同上但 `rounded-full`，未激活为 `bg-white` |
| 通知红点 | `rounded-full bg-[#000000] px-1.5 py-0.5 text-[10px] font-medium text-white` |

### 7.10 页头（PageHeader）

**每个页面必须使用同一个页头组件**，不要在页面里自己造标题栏。

- 左侧：手机端汉堡按钮（`lg:hidden`）+ 标题。标题桌面显示完整描述文案（`hidden lg:inline`），移动显示短标题（`lg:hidden`）。
- 标题样式：`text-base font-semibold md:text-xl`，颜色 `#000000`。
- 右侧 `children` 放页面级控件（搜索、筛选、按钮），容器 `flex shrink-0 items-center gap-3`。
- 宽屏控件容器统一：`flex items-center gap-1 rounded-[2px] bg-[#ECECEC] px-2 py-1.5`，内部搜索框白底、筛选按钮黑底激活。

### 7.11 满高页与二级栏同构

对话页、知识页使用「页面内左栏 + 主内容」，外层 `flex h-[calc(100%-4rem)]`，两栏各自 `overflow-y-auto`。二者必须视觉一致：

- 左栏宽 `w-[260px]`、`border-r border-[#E5E5E5]`、`bg-[#F5F5F5]`
- 顶部**通栏黑底按钮**（+ 图标 + 动作名）
- 导航项双行：主行（`h-5 w-5` 图标 + 标题）＋ 次行（`pl-6` 灰色 12px 描述）；激活项 `bg-[#d5e3f6]`
- 分组小标题：`text-[11px] tracking-widest text-[#A0A8B4]`
- 底部 `border-t border-[#F0F0F0]` 统计区：小标题 + 白底卡片（主行粗体 + 次行灰字 + 状态胶囊/进度条）
- 手机端（`< lg`）左栏收成抽屉，由页头下方的黑底按钮触发

### 7.12 空状态

虚线框 + 居中文案，直角：

```tsx
<div className="rounded-[2px] border border-dashed border-[#D9D9D9] bg-white p-12 text-center">
  <p className="text-sm text-[#A0A8B4]">未找到匹配的工具</p>
</div>
```

功能未开发的大块区域用同样的虚线框，文案 `该功能开发中...`，内边距可缩到 `p-8`。

### 7.13 全局提示（Toast）

屏幕正中，3 秒自动消失：

```tsx
className="fixed left-1/2 top-1/2 z-[100] flex max-w-[min(88vw,400px)] -translate-x-1/2 -translate-y-1/2 items-center gap-3 rounded-[4px] border border-[#E5E5E5] bg-white px-5 py-3.5 shadow-[0_16px_48px_rgba(0,0,0,0.18)]"
```

图标按类型着色（info 黑 / warn `#9A6B0A` / error `#B91C1C`），文本 `text-[15px] text-[#1F1F1F]`。

### 7.14 表单行

输入框：`rounded-[2px] border border-[#E5E5E5] bg-white` + 描述性占位符 `placeholder:text-[#999999]`，高度 `h-8`（页头内）/ `h-9`～`h-10`（内容区）。
成对出现的输入 + 按钮在同一行，按钮在右，禁用态用灰底（`disabled:opacity-*`）。
输入框内嵌图标时用 `pl-9` 让开 `absolute left-3.5` 的放大镜。

### 7.15 空态插画位（对话区）

对话区没有消息时展示：黑底方块图标（`h-12 w-12 rounded-[2px] bg-[#000000]` + 白色图标）+ 一句主文案（`text-sm text-[#000000]`）+ 一句灰色说明（`text-xs text-[#8A8A8A]`，居中，最大宽度受限）。

### 7.16 登录 / 注册页

**全站布局的唯一例外**：不进应用外壳（无侧边栏、无页头、无页脚），整屏灰底居中一张白卡。两页同构，只有字段数量、标题与底部链接不同。

```
灰页面（整屏 bg-[#ECECEC]，内容垂直水平居中，px-4 py-10）
└─ 卡片 max-w-[380px] rounded-[2px] bg-white p-8
   ├─ 品牌区（居中）：黑底方块 h-12 w-12 rounded-[2px] bg-[#000000] + 白色 Logo h-6 w-6
   │   标题 mt-4 text-xl font-semibold text-[#000000]
   │   描述 mt-1 text-xs text-[#8A8A8A]
   └─ 表单区 mt-7
        ├─ 字段之间 space-y-4
        ├─ 表单级错误行（可选，见下）
        └─ 通栏黑底按钮 mt-6 px-4 py-2.5 text-sm（§7.3 常规档）
└─ 卡外次要操作 mt-4 text-center text-xs text-[#8A8A8A]，其中链接 text-[#000000] underline-offset-2 hover:underline
└─ 品牌字 NEXUS OS mt-8 text-center text-[11px] tracking-[0.1em] text-[#A0A8B4]（Sekuya 字体）
```

- 卡片是**页面上唯一的焦点容器**，内边距取 `p-8`（比信息卡的 `p-5` 大一档）——它不与其他卡片并排，需要更多呼吸空间。
- **字段行**：`label` 在输入框上方（`text-xs text-[#8A8A8A]`，与输入框间距 `mt-1.5`），字段说明（规则、格式要求）在输入框下方（`mt-1.5 text-xs text-[#999999]`）。
- **字段级错误**：替换说明文字，颜色转 `#B91C1C`，同时输入框描边转 `border-[#B91C1C]`。
- **表单级错误**（如「用户名或密码不正确」）：灰色内嵌块 + 红字，`rounded-[2px] border border-[#E5E5E5] bg-[#F5F5F5] px-3 py-2 text-xs text-[#B91C1C]`，位于按钮上方。
- **错误提示的生命周期**：字段级与表单级错误都是**上一次提交的快照**，不随输入变化自动消失。规则是——某个字段被编辑过，它的旧错误立即隐藏；表单里任意字段被编辑过，表单级错误立即隐藏；下一次提交时全部清空，由服务端重新判定。理由：用户把 7 位密码改成 8 位后，「密码至少 8 位」还挂在下面，读到的就是「我明明改对了，它却说我不对」——这是提示的错，不是用户的错。实现见 `src/hooks/use-dirty-fields.ts`。
- 页面级标题不是页头组件（§7.10）——这是本形态对「页面必须有统一页头」的**显式豁免**。

### 7.17 受保护首页（过渡形态）

**这一屏的应用内容还没设计，现在放的是占位（Hello world）。** 登录成功后应当直接看到**应用的第一屏**，而不是一张「你已登录」的说明卡——登录成功这件事不需要页面向用户复述。

```
整屏（body 底色 #F5F7FA，内容垂直水平居中）
├─ 居中：text-2xl font-medium tracking-tight 的占位标题（Hello world）
└─ 右上角 absolute right-4 top-4：次要文字按钮「退出登录」
   text-xs text-[#8A8A8A] underline-offset-2 hover:text-[#000000] hover:underline
```

- **不要卡片、不要品牌区、不要问候语。** 这一屏是应用本身，不是认证流程的一部分；视觉上它应当看起来像「已经进到屋里了」。
- **「退出登录」是临时的**：它最终属于应用外壳的页头（§5.1），外壳落地后从本页删掉。放在这里只是为了让登出在今天就可用。
- 页面**豁免统一页头**（§7.10），豁免理由与 §7.16 相同：它还没有进外壳。
- 额外色值与类名：**无**。文字按钮的取值沿用 §7.16 卡外链接的写法。

## 八、图标

- **只用 Lucide React**，不引入第二个图标库，不用 emoji 当图标。
- 尺寸阶梯：`h-3 w-3`（极小行内）、`h-3.5 w-3.5`（次级）、`h-4 w-4`（默认）、`h-5 w-5`（导航/页头）、`h-6 w-6`（一级侧边栏）。
- 图标颜色跟随文字层级（`#1F1F1F` / `#666666` / `#8A8A8A`），默认继承 `currentColor`。
- 按钮内图标自动用 `[&_svg]:size-4` 对齐，不要手动改。
- Lucide 保持默认描边宽度（2px），不做加粗或填充化。

## 九、禁令

以下写进代码即视为违规，不是风格偏好：

1. **彩色徽章 / 彩色大面积底色。** 状态用圆点，选中用 `#d5e3f6` 或黑底白字。唯一的例外是工具卡的图标着色（见 §10）。
2. **给常规卡片加阴影或边框** 来区分层次 —— 层次靠底色交替。
3. **随手用 `rounded-md` / `rounded-lg`** 代替 `rounded-[2px]`。
4. **页面自建标题栏** —— 一律走统一的页头组件。
5. **脱离主题变量硬编码新色值** —— §2 以外的颜色需先加进本文。
6. **在组件里写自定义 CSS** —— Tailwind 工具类优先；仅 `globals.css` 承接主题变量与 Markdown / 快照阅读区排版。
7. **正文出现 `font-bold` 及以上**。

## 十、需要收敛的现存偏差

界面实现中与本文冲突的地方，一律以本文为准：

| 位置 | 现状 | 统一为 |
|---|---|---|
| 工具卡图标 | 59 个工具各自取一组 Tailwind 色板，深浅档（`-500` / `-600` / `-700` / `-800`）混用 | 保留「一工具一色」作为身份识别（**唯一特许的彩色区**），但收敛成统一配方：文字 `text-<色>-500` + 图标底 `bg-<色>-50`，不再混用更深档位 |
| 设置页容器 | shadcn `Card` + `shadow-[0_1px_3px_...]` | 直角白卡 `rounded-[2px] bg-white p-5`，无阴影 |
| 设置页占位块 | `bg-[#F8FAFC]`（偏蓝的白） | `bg-white` 或 `bg-[#F5F5F5]` |
| 黑底按钮 hover | 两种写法混用（`hover:opacity-85` / `hover:bg-[#333333]`） | 文字按钮用 `hover:bg-[#333333]`，纯图标小按钮用 `hover:opacity-85` |
| 侧栏导航圆角 | `rounded-xl`（14px） | 保留，作为 §3 的唯一例外 |
