### 4. 输入法组合态回车误发送（IME composition）

- **日期**：2026-08-25
- **现象**：输入法候选词还没敲定时按回车，消息被直接发送出去。比如用输入法敲几个字母、习惯按一下回车把单词"落"下来，结果对话框把这个回车当成了发送命令，聊天打到一半就提前发出去。
- **根因**：`textarea` 的 `onKeyDown` 只判断了 `Enter && !shiftKey` 就调用发送，没有区分「输入法组合输入态」（IME composition）。候选窗还开着时按回车，浏览器的 `keydown` 事件一样会触发，于是被误当成"发送回车"。
- **解决方案**：给输入框加 `onCompositionStart` / `onCompositionEnd`，用 `composingRef` 记录组合态。`onKeyDown` 里增加 `&& !composingRef.current` 条件：候选词未敲定（composition 窗口内）按回车不发送，正常输入（无候选）回车照常发送。
- **一句话**：回车发送前必须先排除 IME 组合态，否则「回车确认候选」的输入习惯会误触发送。

### 3. 深度思考档位与供应商枚举不一致（DeepSeek 传非法 low）

- **日期**：2026-08-25
- **现象**：前端「深度思考」统一渲染「低/高/最高」三档，切到 DeepSeek 模型时选「低」也能点中、能发送，但不确定到底有没有真正生效。
- **根因**：low/high/max 是前端自己定义的统一枚举，但 DeepSeek 官方 `reasoning_effort` 只认 `high` / `max` 两个值，`low` 不是合法枚举。选「低」时把 `low` 原样透传给 DeepSeek，属于未定义行为（可能被归一化到 high，也可能报错），这一档等于"假的"。而 OpenRouter（openai 方言）那边 low/high/max 映射成官方 low/medium/high 是真三档，两套供应商枚举根本不匹配。
- **解决方案**：档位不再写死三档，改成「按模型声明」。在模型注册表给每个支持思考的模型加 `thinkingEfforts` 字段（DeepSeek 系只 `["high","max"]`，Ox Alpha 是 `["low","high","max"]`），前端档位按钮按模型动态渲染、恢复偏好时按模型档位表过滤非法值，后端 route 也用同一张表兜底。默认档位跟着模型走（DeepSeek 默认 high、OpenRouter 默认 low）。
- **一句话**：档位枚举必须对齐供应商真实取值，前端统一枚举 + 原样透传 = 迟早传非法值。

### 2. 懒加载 ≠ 虚拟列表（对话消息流卡顿）

- **日期**：2026-08-25
- **现象**：对话消息流已经做了分页懒加载（每页 50 条，往上滚用 `before` 参数拉更早的），以为解决了卡顿，但长时间往上翻历史、攒到几百条之后页面还是卡。
- **根因**：懒加载是「**追加**」不是「替换」。往上滚加载更早消息时数组只增不减（`setMessages(prev => [...older, ...prev])`），已经加载回来的消息会被**全部渲染成 DOM 节点**。所以卡不卡只看「累计渲染的节点总数」，跟每页多少条无关——10 条一页滚 50 次、和 50 条一页滚 10 次，最终都是 500 个节点，一样卡。
- **解决方案**：
  - **短期**：如果真实场景很少把消息流滚到几百条，分页懒加载已经够用，不必动。
  - **根治**：上「虚拟列表」——不管内存里攒了多少条，页面上永远只渲染可视区 + 上下缓冲区那几十个节点，其余用占位撑起总高度。三个关键点：① 动态高度用 `ResizeObserver` 测量；② 流式输出高度持续增长要实时更新；③ 处理滚动位置锚定（停在中间时新内容不能把视口顶乱）。可选 `react-virtual`（TanStack Virtual）或 `react-window`，也能手写练手。
- **一句话**：懒加载管「进得慢」，虚拟列表管「存得少」，两者是两个层面，不冲突也不互相替代。

### 1. API Key 硬编码进 Git 仓库

- **日期**：约 2026-08-24
- **现象**：调大模型时图省事，把 API Key（DeepSeek / OpenRouter / Tavily 等）直接写死在代码文件里。
- **根因**：一旦 key 进了 Git 历史，即使之后删除、公开仓库也会泄露，等于把扣费凭证交出去。
- **解决方案**：一律存在本地 `.env.local`（加入 `.gitignore`，不入 Git），代码里通过环境变量读取。
- **一句话**：所有 API Key 只进 `.env.local`，永不入库、永不硬编码。
