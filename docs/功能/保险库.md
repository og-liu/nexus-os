# 保险库

| 状态 | 开始日期 | 最近更新 |
|---|---|---|
| ✅ 已上线（v0.9.0） | 2026-10-29 | 2026-10-30 |

> 一句话：一个**完全新增**的工具——左边群组分类、中间条目列表、右边条目的全部内容；每条记录是「标题 + 自定义键值对」，外加复制、密码生成、批量移动。

---

## 一、要什么

**做：**

- **工具页** `/tools/vault`：三栏布局——左栏群组导航、中栏条目列表、右栏选中条目的详情
- **落库**：两张新表 `vault_groups` / `vault_items`，全部按 `user_id` 隔离；条目的群组可为空（未分组）
- **条目**：标题（默认「未命名」，重名自动补序号）+ **自定义字段**（键值对，可增删、可拖拽排序）；每个字段可一键复制、可一键生成 20 位随机串；**每个字段可设定「默认遮挡」**——在编辑弹窗里点眼睛，保存后右栏与中栏就按这个设置显示（遮挡时是 `***`，点眼睛可临时看见）
- **群组**：新建 / 重命名 / 删除（二次确认；删群组不删条目，组内条目降为未分组）
- **批量**：复选框多选 → 批量移动到指定群组 / 批量删除
- **搜索**：只搜标题，输入即过滤
- **目录同步**：`tool-catalog` 新增一条 `vault`（分类「生活」、状态「可用」），工具卡可点

**主动放弃（本版不做，不是遗漏）：**

| 放弃项 | 原因 |
|---|---|
| 字段值加密 / 主密码 | 主人明确要求一期不做（个人工作台）。**明文存储要在文档里写明白**，见《数据库/保险库条目表》§七。做一半的加密（密钥在进程里、明文进日志）比明文更危险 |
| 字段「类型」（文本/密码/URL） | 类型一进来，每加一个字段就多一次下拉选择；收益只是「密码行显示成圆点」。这个工具要的是记得住、找得到、复制得走 |
| 字段值搜索 | 需求定的是「只搜标题」。字段值搜索要读 JSON 或建 `vault_item_fields` 表，等真有需要再说 |
| 群组嵌套 / 群组排序 | 一层分类够用；嵌套要定义「删父组时子组怎么办」。手动排序要给群组加 `position` 列并批量重排 |
| 收藏 / 星标 / 图标 / 颜色 | 参考图里有，砍掉：全站黑白灰基调，图标只会让左栏变成彩色贴纸 |
| 附件 / SSH 密钥 / 2FA / 到期日 / 备注 | 参考图里的固定字段区块，全部砍掉——本工具只有「标题 + 自定义字段」 |
| 删除撤销 / 回收站 | 同便签：软删除会让每条查询都得带 `deleted_at IS NULL`；二次确认更便宜 |
| 拖拽库（dnd-kit） | 只为弹窗里几行字段排序，引两个包不值；手写 pointer 事件足够，见「关键决策」 |
| 条目历史的版本记录 | 没有「上一次的值是多少」这种需求；真要做得加版本表 |

## 二、界面

### 2.1 工具页 `/tools/vault` 整体骨架

**与其它工具页最大的不同：这是全站第一个「应用型」页面，不是「文档流」页面。**

便签 / 待办 / 工作日历都是「一列内容往下排、整页滚动」；保险库要的是**三栏各自滚动、整页不滚**（像 Finder / 邮件客户端）。所以：

- 页面根 `flex h-full overflow-hidden`
- **没有 `PageHeader`**：页签栏（`工具 ×`）已经承担了「我在哪、怎么切走」，再叠一条「‹ 保险库」就是同一件事说两遍——主人的原话是「上面已经有多页签导航了，没必要多整这么一行」。代价是那条页头里的**手机汉堡按钮**（打开全局侧边栏）跟着消失，所以它挪到中栏顶行的最左边（`lg:hidden`，≥ lg 有常驻侧边栏，不需要）
- 三栏区 `flex min-h-0 flex-1 overflow-hidden`——**`min-h-0` 不能省**，flex 子项的默认 `min-height` 是 `content`，三栏会被内容撑破、整页开始滚

```
页签栏（外壳的 TabBar，页面自己不再画标题行）
┌──────────┬─────────────────────────────┬──────────────────┐
│ 左栏 208 │ 中栏（弹性）                 │ 右栏 384          │
│          │                             │                  │
│ 所有条目 │ 搜索框            [新建]     │ 标题             │
│ ─ 群组   │ ┌─ 标题 ─ 字段1 ─ 时间 ─┐    │ 修改时间  [编辑][删除]│
│ ⊞ 银行 3 │ │ ☐ 招商银行 … ashie…  │    │ ─────────────── │
│ ⊞ 阿里云2│ │ ☐ 阿里云    … …      │    │ 卡号   8821319 [复制]│
│          │ └──────────────────────┘    │ 密码   ……      [复制]│
│ + 新建群组│                             │                  │
└──────────┴─────────────────────────────┴──────────────────┘
```

### 2.2 左栏：群组导航

- 顶部「**所有条目**」一行，右侧显示**全部条目总数**（不是未分组数）。它是聚合视图，点它 = 中栏列出这个人的全部条目（含未分组的）
- 下面细分隔线 + 「群组」小标题 + 右侧 `+` 按钮（新建群组）
- 每个群组行：名称 + 条目数（右对齐、灰色小字）
- **排序：最新建的在上**（`created_at DESC`）——新建的群组立刻出现在顶部，和「建完自动切过去」配合，视线不用上下找
- 选中态：黑底白字（与侧边栏选中态一致，全站一种高亮方式）
- 群组行 hover（触屏常显）出现 `⋯` 按钮 → 菜单「重命名 / 删除」
- **新建成功后自动切到那个群组**：建完不用在左栏里再找一遍，直接看到它被高亮、中栏显示它（新群组是空的，所以是空态）。实现上 `createGroupAction` 会把新 id 放 `createdId` 返回，前端据此切视图
- **删除群组**：弹确认框，文案 `删除群组「银行」？该群组还有 3 条记录，删除后它们会变成未分组，记录本身不会丢失。` 没有条目的群组省略第二句。确认按钮黑底「确认删除」
- 空态（一个群组都没有）：「还没有群组」+ 小字「点上面的 ➕ 建第一个」

### 2.3 中栏：条目列表

**列头是动态的**——这是本页最容易做错的地方：

```
列头 = 标题 + ⌈当前视图内所有条目字段名的并集，最多 4 个⌉ + 修改时间
```

- 「并集」按**首次出现顺序**排（第一条记录的字段顺序打头），保证列头稳定、不随选择跳动
- 某条记录没有这一列 → 该格显示 `—`（灰色）
- 标题列与时间列**永远存在**：标题必然有值，时间是排序依据，它们回答「这条是什么、什么时候动过」
- 动态列最多 4 个；第 5 个及以后的字段只在右栏看（再多列，中栏会挤成一条缝）

**列数随中栏自身宽度退档**（容器查询，不是视口断点——三栏时中栏宽度只有视口的一半，用视口断点会犯「窗口很宽、中栏很窄，照样显示 4 列」的错）：

| 中栏可用宽度 | 显示 |
|---|---|
| < 560px | 标题 + 修改时间（2 列） |
| ≥ 560px | 标题 + 2 个字段列 + 修改时间 |
| ≥ 760px | 标题 + 4 个字段列 + 修改时间 |

- 每行左侧一个 **复选框**，常驻（不藏 hover——手机没有 hover，藏起来就永远勾不上）
- 行点击 → 选中该条，右栏渲染；选中行整行 `bg-[#F5F5F5]`（不用蓝色高亮，全站黑白灰）
- **整行是手型光标**（`cursor-pointer`），空白处也算——点哪都表示「这一行可以操作」
- **双击整行直接打开编辑弹窗**：编辑不必「先选中、再点右栏铅笔」两步。标题与字段一起进弹窗
- 行上加 `select-none`：双击时浏览器会顺手选中文字，看着像出了 bug；列表里的值本来就截断，要看完整值去右栏复制
- 字段值截断：`truncate`（单行、超长省略），完整值在右栏
- 字段列默认显示 `***`；点右栏那只眼睛，中栏对应的格子**一起露出来**（两处共用同一份 `revealed` 状态，不然会出现「一边露一边藏」）
- 表头「修改时间」不可点排序（排序固定时间倒序，见「关键决策」）

**搜索框**：占位文字「搜索标题」，输入即过滤（前端过滤，不走服务端）；有输入时右侧出现清除 `×`。搜索改变时**选中态保留**（只要那条还在结果里），不在结果里就清空选中

**批量操作条**：勾选 ≥1 条后，列表上方浮出一条：

```
已选 3 条   [移动到 ▾]  [删除]              [取消选择]
```

- 「移动到」打开一个小组件：列出全部群组 + 第一项「未分组」，点一项即执行
- 「删除」进二次确认：`删除选中的 3 条记录？删除后无法恢复。`
- 执行成功后清空选择、刷新列表、右栏按「当前视图第一条」重新选中

**空态：**
- 视图里没有任何条目：`这里还没有记录`（群组视图时是 `这个群组还没有记录`）+ 黑字按钮「新建一条」
- 搜索无结果：`没有标题包含「xxx」的记录` + 灰字「换个词试试」

### 2.4 右栏：条目详情

**有选中：**

```
┌──────────────────────────────────────┐
│ 招商银行信用卡                        │ ← 标题 18px 半粗
│ 修改于 2026-10-29 16:12   [编辑][删除] │ ← 12px 灰字 + 两个图标按钮
├──────────────────────────────────────┤
│ 卡号                       [👁] [复制] │ ← 字段名 11px 灰 + 眼睛（常显）+ 复制（hover 才显）
│ ***                                   │ ← 默认遮挡；点眼睛才显示真值
│ 密码                       [👁] [复制] │
│ ***                                   │
└──────────────────────────────────────┘
```
- **是否遮挡由字段自己的 `hidden` 决定**（在编辑弹窗里设，跟着记录存）：`false` 直接显示真值，`true` 显示 `***`；点眼睛能**临时**看一眼，不写回库
- 眼睛与复制**都常显**（有值才给）：视力上并排两个小图标，点哪个都不会猜错；复制永远拿真值
- 空值不显示眼睛：那行显示 `（空）`，灰色斜体——没有东西可藏，也不用点
- 值 `break-all`（密码/卡号没有空格，`break-words` 撑不住长串）；遮挡时用**固定 12 个星号** + 等宽字体 + 宽字距，一眼看出是「藏起来了」——不按真实长度生成，长度本身也是信息
- 复制成功 `toast.success("已复制")`；失败（浏览器拒绝剪贴板权限）`toast.error("复制失败，请手动选中")`
- 编辑 / 删除在标题右侧；删除进二次确认：`删除「招商银行信用卡」？删除后无法恢复。`

**无选中（空态）：**

> **在左边选一条记录**
> 这里会显示它的全部字段；点上面的「新建」也可以随时记一条。

（这是主人要求「文案你来想」的地方：先说要做什么动作，再给一条备选路径，比一句「暂无数据」有用。）

### 2.5 新建 / 编辑弹窗

新建与编辑**共用一个组件**，差别只在初始数据与标题：

```
┌────────────────────────────────────────┐
│ 新建记录 / 编辑记录                  ✕ │
├────────────────────────────────────────┤
│ 标题  [未命名                        ] │
│ 群组  [未分组                      ▾ ] │
│                                        │
│ 自定义字段                    [+ 添加] │
│ ⋮⋮ [卡号          ] [8821319      ] 🎲 🗑 │
│ ⋮⋮ [密码          ] [•••••••••••••] 🎲 🗑 │
│                                        │
├────────────────────────────────────────┤
│                            取消   保存 │
└────────────────────────────────────────┘
```

- **标题**：输入框，新建时预填「未命名」并**全选**（进来直接打字就是替换）。留空保存时按「未命名」处理
- **重名自动补序号**：新建时若已存在同名标题，存成「未命名 2」「未命名 3」……（只对空标题/未命名生效，用户自己起的名不自动改——用户想让两条同名是合法的）
- **群组**：原生 `select`，但 **`appearance-none` 掉浏览器自带的箭头**、右侧自己放一个 `ChevronDown`（原生箭头贴着边框、`padding-right` 管不到它，右边距调不出来）；不用第三方下拉组件——项目没有，也不为这一个字段引一个
- **自定义字段行**：`⋮⋮` 拖拽把手 + 字段名输入 + 值输入 + 🎲 + 删除
  - 拖拽排序：**手写 pointer 事件**（见「关键决策」），按住把手上下拖，实时换位；键盘可用 `↑`（把该行上移一位）——纯指针拖拽对只用键盘的人等于不存在
  - 🎲 生成：把值替换成 20 位随机串，字符集 `ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnopqrstuvwxyz23456789!@#$%^&*`
    - **去掉易混字符** `0 O o 1 l I`（抄写时会看错）
    - 生成前如果该行已有值，**直接覆盖**、不弹确认——用户在弹窗里点它就是要换掉，多一次确认反而烦（想撤销就点取消）
  - 🗑 删除该字段行
  - **每行的值后面一个眼睛**：改的是**这一格保存后的默认状态**——睁开 = 外面直接显示真值，闭上 = 外面显示 `***`。它不是「这一次看不看」，保存后外面照着它显示
    - 新建行默认睁开；编辑时按已存的值回填
    - 闭上时弹窗里的值输入框变圆点（`type="password"`），方便你确认自己敲了什么再决定要不要藏
  - 字段名叫空的：保存时整行**静默丢弃**（用户加了一行又没填名字，说明他不要这行）
- **添加字段**：追加一行空行、焦点落到新的字段名输入
- **保存**：
  - 服务端校验失败（标题超长、字段过多、群组不属于自己）→ 弹窗内顶部红字提示，**不关窗**，输入内容不丢
  - 成功 → 关窗、中栏刷新、右栏选中这条（新建的也直接选中）、toast **带上标题**：「招商银行信用卡」已保存（服务端可能把「未命名」补成「未命名 2」，所以标题从返回的快照里取，不用提交时的那个）
  - `⌘/Ctrl + Enter` 保存；`Esc` / 「取消」/ 点遮罩都**直接关闭并丢弃改动**——不做「有未保存改动就拦一下」的防手滑。主人否得很干脆：「我都要取消了，为什么还要保存」。要留住改动就点保存，取消这个动作本身就表达了意图
- **移动端**：`Modal` 本身就是全屏形态（< sm），字段行改为上下堆叠（名字在上、值在下）

### 2.6 响应式（三档，都是独立版式，不是压缩）

全局侧边栏是 `lg`(1024) 起常驻、宽 80px（图标版）。所以内容区宽度 = 视口 − 80（≥1024）/ 视口（<1024）。

| 档位 | 视口 | 布局 |
|---|---|---|
| 宽屏 | ≥ 1280 | **三栏并排**：左 208 / 中弹性（约 600–900）/ 右 384。三栏各自 `overflow-y-auto` |
| 窄屏 PC / 平板横 | 1024 – 1279 | **两栏**：中 + 右（340）。左栏收进抽屉，由中栏顶部的「群组」按钮打开 |
| 平板竖 | 768 – 1023 | **两栏**：中（最小 420）+ 右（最小 300）。左栏同样走抽屉 |
| 手机 | < 768 | **单栏逐层**：列表页 → 详情页。列表页顶行最左是**汉堡**（打开全局侧边栏，因为页头没了），下面一行是群组横向 chip 条（`所有条目` + 各群组，横滑）；点条目切到详情页，详情页顶部有「← 返回」 |

- **≥768 的抽屉**：点「群组」按钮从左侧滑出 240px 面板 + 遮罩（复用 `AppShell` 抽屉那套观感），选中群组后自动关闭
- **手机为什么用横滑 chip 而不是抽屉**：手机上「切群组」是高频动作，抽屉要点两下（开、选）；chip 条点一下就切，且当前群组始终可见
- **手机详情页**：整页替换列表（不是叠在下面），顶部 `← 保险库 / 群组名`，右侧「编辑」「删除」
- **手机弹窗**：`Modal` 全屏；字段行上下堆叠；底部按钮贴安全区
- 三档用**互斥显隐**（`hidden xl:flex` / `xl:hidden`）而不是 JS 读视口——首屏 SSR 不闪（同《工具中心》的做法）

## 三、数据模型

```sql
CREATE TABLE IF NOT EXISTS vault_groups (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id    INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  name       TEXT    NOT NULL,
  created_at INTEGER NOT NULL,
  UNIQUE (user_id, name)
);

CREATE INDEX IF NOT EXISTS idx_vault_groups_user_id ON vault_groups(user_id);

CREATE TABLE IF NOT EXISTS vault_items (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id    INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  group_id   INTEGER REFERENCES vault_groups(id) ON DELETE SET NULL,
  title      TEXT    NOT NULL,
  fields     TEXT    NOT NULL DEFAULT '[]',
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_vault_items_user_id ON vault_items(user_id);
CREATE INDEX IF NOT EXISTS idx_vault_items_group_id ON vault_items(group_id);
```

设计要点：

- **`group_id` 用 `ON DELETE SET NULL`**：删群组时条目**自动**变未分组，不需要应用层「先搬再删」，也不会因为漏搬而连坐删除。**前提是连接开着 `foreign_keys = ON`**（`createConnection()` 已开，SQLite 默认是关的）
- **`fields` 存 JSON 数组**：`[{"key":"卡号","value":"8821319"}]`。用数组不用对象是为了**保序**（用户可拖拽）；这是《数据库/README》§三「一列只存一个值」的**登记例外**，理由与推翻条件见《数据库/保险库条目表》§七
- **`(user_id, name)` 唯一**：同一个人不能有两个同名群组（左栏里两个「银行」谁也分不清）；不同用户互不干扰
- **排序**：`ORDER BY updated_at DESC, id DESC`。末尾 `id DESC` 是毫秒撞车时的稳定兜底
- **移动群组也刷新 `updated_at`**：移完立刻要在新群组里一眼看到
- **群组表没有 `updated_at`**：改名不参与任何排序，留一列没人读的列会被误以为「群组能按最近编辑排」

字段逐个解释与常用查询见《数据库/保险库群组表》《数据库/保险库条目表》。

## 四、关键决策

| 决策点 | 选择 | 理由 | 否决的备选 |
|---|---|---|---|
| 页面形态 | **三栏、整页不滚、各栏自滚** | 这是「反复查用」的工具，看列表和看详情要同时在场；滚动整页会让右栏跟着列表跑掉 | 列表页 + 详情页两跳（每次看字段都要离开列表）；抽屉详情（遮不住列表） |
| 左栏与全局侧边栏叠加 | ≥1280 才三栏，1024–1279 左栏收进抽屉 | 全局图标栏占 80px，三栏至少需要 208+520+340=1068 的内容宽度 | 所有尺寸都硬塞三栏（1024 下中栏只剩 300px，列头全挤没） |
| 列头 | 标题 + 字段并集（最多 4）+ 时间，**动态生成** | 主人原话「用户名 / URL 没了就没了，全部由自定义字段来决定」；同一群组里的记录结构通常一致，横向比较才有意义 | 固定三列（字段不固定，只能空着）；只显示标题（信息密度太低，扫读全靠点） |
| 动态列的取法 | 当前视图内**并集**、按首次出现顺序、最多 4 | 取并集才能跨记录比较；4 列是三栏下中栏能容下的上限 | 取所选条目的字段（切条目时列头乱跳）；全部字段（列太多，每列被挤成一条缝） |
| 列数退档 | **容器查询**（中栏自身宽度） | 中栏宽度 ≠ 视口宽度（三栏时只有一半），视口断点会算错 | 视口断点 `md:` / `lg:`（宽屏但中栏窄时照样挤） |
| 排序 | 固定 `updated_at DESC`，表头不可点 | 只有一个排序需求：「最近动过的在最上面」。可点排序要维护 `sortKey/dir` 状态、每个可选列建索引，收益为零 | 点列头多列排序 |
| 搜索 | 只搜标题、前端即时过滤 | 需求定死的范围；个人量级（几百条）全量在前端过滤，无网络往返、无防抖延迟 | 搜字段值（要读 JSON 或建字段表）；服务端搜索（多一次往返，还要处理竞态） |
| 字段排序 | **手写 pointer 拖拽 + 键盘 ↑** | 只为弹窗里几行做排序，dnd-kit 两个包 ~40KB；行高固定（44px），位移 ÷ 行高 = 目标下标，算法十行写得完，还能讲清原理 | `@dnd-kit/core` + `@dnd-kit/sortable`（功能强，但为 5 行字段引入两个依赖）；HTML5 `draggable`（**触屏完全不工作**） |
| 拖拽把手 | 只在 `⋮⋮` 上响应 | 整行可拖会和「选中输入框文字」打架；有把手用户才知道能拖 | 整行可拖（手机上根本没法选文字） |
| 密码生成 | 每行一个 🎲，默认 20 位、去易混字符 | 没有字段类型，所以「生成」是**行级动作**而不是「密码类型字段的属性」；去 `0O1lI` 是因为抄写时看错 | 给字段加类型再判断（每加一个字段多一次下拉选择）；全局一个生成器面板（还要选粘到哪一行） |
| 群组删除 | 二次确认 + **真删群组、条目降为未分组** | 删盒子不该烧掉盒子里值钱的东西；`ON DELETE SET NULL` 让这条规则由数据库保证，应用层忘了也不会错 | 连坐删除条目（灾难）；软删除群组（查询到处要带条件） |
| 群组名唯一 | 同一用户内唯一 | 左栏是导航，两个同名群组每次都要猜 | 允许重名（省一次报错，换来长期困惑） |
| 批量操作 | 复选框 + 浮出操作条 | 移动/删除都是多条目动作；不做批量就得一条条点 | 右键菜单（触屏没有右键）；长按多选（发现不了） |
| 弹窗 vs 独立页 | **弹窗**（复用 `ui/modal`） | 编辑时列表还在背后，改完立刻看到它复位到哪；`Modal` 已有移动端全屏形态 | 独立编辑页（为几个字段开一页）；右栏原地编辑（三栏里最窄的一栏，输入框会被挤爆） |
| 字段值的遮挡 | **默认状态存在字段上**（`fields[].hidden`）：弹窗里设，右栏与中栏照着显示；临时的「看一眼」只在本会话翻转、不写回 | 「这一格打开时想不想看见」是对数据的设定，属于记录；而「这一眼谁在看」是临时状态，属于屏幕。把两者分开，才不会出现「保存后再打开又变了」。中栏与右栏**共用同一份临时状态**，否则会一边露一边藏 | 全局一个眼睛开关（分不清是哪个字段，等于没遮）；把临时观看也写回库（刷新后又变，用户会以为没生效）；按字段类型判断（没有类型，也不想为它引入） |
| 复制 | 每个字段一个复制图标 | 保险库最常用的动作就是「把值拿走」；没有它等于每次都要手动选中 | 整条复制（字段混在一起，粘出去还得拆） |
| 空态文案 | 「在左边选一条记录」+ 备选路径 | 先说要做什么动作，再给第二条路；比「暂无数据」有用 | 「没有选择对象」（机器语气） |

**工具接入方式**：工具卡统一链到 `/tools/${slug}`，而手写路由 `/tools/vault` 是**静态段**——Next 的路由匹配里静态段优先于动态段，所以卡片点进来自动命中真页面，`/tools/[slug]` 那条兜底根本不执行。这意味着接入只需要两步：目录里登记一条 + 建一个同名的静态路由目录（`src/app/(app)/tools/vault/page.tsx`），**不需要在 `[slug]` 页面里做任何分流**。便签 / 待办 / 工作日历早就是这么跑的。

约束（沿用项目规矩）：

1. `src/lib/` 下不 import React 组件；数据访问与 Server Action 可以，视图不行
2. 表结构唯一权威仍是 `initSchema()`
3. 不新增运行时依赖（拖拽手写）
4. 路由必须落在 `src/app/(app)/tools/vault/`

## 六、验收标准

**正常路径**

1. 打开 `/tools/vault`：三栏出现；左栏有「所有条目 (0)」；中栏空态「这里还没有记录」；右栏空态「在左边选一条记录」。
2. 左栏 `+` → 输入「银行」→ 群组出现在列表、显示 `(0)`；重名再建一次 → 提示「已存在同名群组」，不新增。
3. 点「新建」→ 弹窗、标题预填「未命名」且全选；加两个字段（卡号 / 8821319、密码 / 点 🎲 后是 20 位随机串）→ 保存 → 弹窗关、中栏出现一行、右栏立刻显示这条的两个字段。
4. 中栏列头出现「标题 / 卡号 / 密码 / 修改时间」——**字段名列头是从数据里来的**，不是写死的。
5. 再建一条只有「客服电话」一个字段的记录 → 列头变成「标题 / 卡号 / 密码 / 客服电话 / 修改时间」的前 4 个字段 + 时间；第一条的「客服电话」格显示 `—`。
6. 点右栏某个值的复制图标 → toast「已复制」；粘贴到别处是完整值。
7. 点「编辑」→ 弹窗回填标题、群组、两个字段；拖住第一行的 `⋮⋮` 往下拖到第二行位置 → 松手后两行交换；保存 → 右栏字段顺序同步变了，刷新后仍是新顺序。
8. 弹窗里聚焦字段名输入，按 `↑` → 该行上移一位（键盘也能排序）。
9. 编辑里把群组从「未分组」改成「银行」→ 保存 → 中栏两栏数量都变（银行 +1、所有条目不变）。
10. 在「银行」里勾选两条 → 操作条出现「已选 2 条」→「移动到 ▾」选「未分组」→ 两条离开当前视图、左栏计数变化。
11. 勾选两条 →「删除」→ 确认框写明「删除选中的 2 条记录」→ 确认 → 两条消失、右栏按当前视图第一条重新选中。
12. 搜索框输入「银行」→ 中栏只剩标题含「银行」的记录，搜索无结果的文案正确；清除 `×` 恢复。
13. 左栏群组 `⋯` →「重命名」→ 改成「银行卡」→ 左栏立刻更新，条目不变。
14. 左栏群组 `⋯` →「删除」→ 文案含「该群组还有 2 条记录，删除后它们会变成未分组」→ 确认 → 群组消失；点「所有条目」两条仍然在，右栏显示它们「未分组」。
15. 切换群组：中栏自动选中该群组**第一条**，右栏立即渲染它。
16. 刷新页面：所有数据都在，顺序与刷新前一致（`updated_at DESC`）。

**负面路径**

17. 未登录直接访问 `/tools/vault` → 跳 `/login`。
18. A 用户的数据被 B 用户查询：数据层单测用两个 `user_id` 跑一遍 → B 取不到 A 的群组和条目、B 改不动 A 的行（影响行数 0）。
19. 用 B 的 `user_id` 建条目时把 `group_id` 塞成 A 的群组 id → 服务端拒绝（`群组不存在`），不落库。
20. 字段名全空、只留几行空行 → 保存时静默丢弃，落库的 `fields` 是 `[]`，界面不报错。
21. 标题 200 字 → 服务端拒绝并存提示，弹窗不关、输入不丢。
22. 直接调 Server Action 传非法 `fields`（不是数组 / 元素不是对象 / 类型不是字符串）→ 拒绝，不抛未捕获异常。
23. 未选中任何条目时点批量操作 → 操作条根本不出现（没有入口）。
24. 删除当前选中的条目 → 右栏回到空态或自动选中下一条（不留「已删除但还显示着」的残影）。
25. 页面里存 `<img src=x onerror=alert(1)>` 当字段值 → 页面按原文字面显示，无脚本执行。

**响应式**

26. 1440px：三栏并排（左 208 / 中弹性 / 右 384）；中栏列头 4 个字段列；三栏各自滚动，滚中栏时整页不动。
27. 1280px：三栏仍在；中栏收窄后列头自动退到 2 个字段列（容器查询生效）。
28. 1100px：两栏（中 + 右 340）；左栏消失、中栏顶部出现「群组」按钮，点开抽屉可切群组。
29. 768px：两栏（中 ≥420 + 右 ≥300），列表只显示标题与时间。
30. 375px：单栏列表页——顶部群组横滑 chip 条（所有条目 + 各群组，可横滑）；点一条进入详情页，顶部「← 保险库」；编辑/删除在详情页右上；点「←」回到列表，群组与滚动位置保留。
31. 375px 弹窗：全屏、字段行上下堆叠、底部按钮不被安全区遮挡。

**门禁**

32. `pnpm exec next typegen` / `pnpm typecheck` / `pnpm lint` / `pnpm test` / `pnpm build` 全过。
33. 单测覆盖：群组唯一、删群组后条目 `group_id` 变 NULL、`user_id` 隔离、批量移动、批量删除、排序（时间倒序 + id 兜底）、字段数组序列化/反序列化（非法 JSON 不崩）、标题校验边界、未命名自动编号、密码生成（长度/字符集/不含易混字符/两次不同）。

## 七、已知的坑

| 坑 | 机制 | 对策 |
|---|---|---|
| 删群组后条目「消失」 | `foreign_keys` 默认**关**，`ON DELETE SET NULL` 不执行，子行变成指向已删群组的孤儿 | `createConnection()` 已开 `foreign_keys = ON`；单测里专门断言「删群组后条目 group_id 是 NULL、条目还在」 |
| 三栏撑破页面 | flex 子项默认 `min-height: auto`，内容会把栏撑高，整页开始滚 | 三栏的父容器 `flex min-h-0 flex-1 overflow-hidden`，每栏自己 `overflow-y-auto`；`min-h-0` 不能省 |
| 中栏列头错位 | 动态列数变化时，`table` 的列宽会跳 | 列宽用 `table-fixed` + 标题列固定比例；字段列等分剩余宽度 |
| 容器查询不生效 | Tailwind 的 `@[560px]:` 需要父元素显式 `@container` | 中栏根节点加 `@container`，且**不要在中间再套一层没加 `@container` 的 div**——容器查询找的是最近的容器祖先 |
| 手写拖拽在手机上拖动整页 | 触摸时浏览器把 pointermove 当成滚动 | 把手加 `touch-action: none`；`pointerdown` 时 `setPointerCapture`，只认设置的 pointerId |
| 拖拽行高不固定导致下标算错 | 用「位移 ÷ 行高」计算目标位置，行高必须已知 | 字段行固定高度（`h-11`，含 44px），不使用 `min-h`；换行时值输入框内部滚动 |
| 拖拽时输入框失焦 | 点把手会先 `blur` 值输入框 | 允许失焦（拖完不回到输入框），不影响数据；保存时统一从 state 读 |
| 误关弹窗丢改动 | `Modal` 自带 `Esc` / 点遮罩关闭 | **不做拦截**（主人明确否决了「按两次」）：取消就是取消，要保住内容就点保存 |
| 复制在非 HTTPS 下失败 | `navigator.clipboard` 只在安全上下文（HTTPS / localhost）可用 | 线上是 HTTPS；失败分支必须给 `toast.error`，让用户能手动选中 |
| 搜索时选中态指向被过滤掉的条目 | 选中 id 还在，但那条已不在结果里 | 过滤后校验：选中项不在结果里就清空选中（右栏回空态） |
| 批量操作后选中残留 | 删除/移动后 id 已失效 | 操作成功后统一「清空选择 + 按当前视图重新选第一条」 |
| JSON 字段被外部改坏 | 库里 `fields` 是文本，可能不是合法 JSON | 读取时 `try/catch`，坏数据当 `[]` 处理并在服务端日志里记一条，不让整个列表 500 |
| 未命名编号无限增长 | 每次新建都要查一遍同名 | 只在标题为空或恰为「未命名」时查，且用一个 `SELECT title ... LIKE '未命名%'` 一次取回再算序号 |
| 时间显示跨时区漂移 | 服务端容器是 UTC | 复用 `src/lib/format.ts` 的 `formatDateTime`（显式 +8），不自己拼 |
| 三栏页在手机上整页滚 | 手机是单栏逐层，但详情页内容长时会滚 | 详情页自身 `overflow-y-auto`，页头固定 |
| 演示数据残留 | 手动测的记录会被当真实数据 | 验收结束前清掉测试行（或换测试账号跑） |
